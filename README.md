## ⚡ Overview

A high-performance, developer-centric interactive portfolio built with modern Web standards, TypeScript, React 19, and Tailwind CSS. It highlights backend architectures, distributed systems telemetry, 300+ DSA algorithmic breakdowns, real-time live GitHub integrations, and interactive CLI simulations.

### 🌟 Key Highlights

- **Interactive Runtime Terminal (WebPty CLI):** Full virtual terminal supporting commands like `help`, `cat`, `curl`, `ping`, `neofetch`, `matrix`, `sysinfo`, `stats`, and `projects`.
- **System Architecture Deep Dives:** Comprehensive architectural breakdowns of production projects including ZenX-Code, FenriX, and real-time Java microservices.
- **04. Algorithmic Rigor & DSA Telemetry:** Interactive 3D tilt cards, algorithmic domain coverage with 3D pop-up interaction, complexity metrics ($O(1)$, $O(\log N)$, etc.), and full Java implementations.
- **Live GitHub Ecosystem:** Real-time repository metrics, commit statistics, dynamic filters, and live GitHub API synchronization.
- **Interactive Development Timelines:** Visual project development lifecycles with phased breakdowns and verification checkpoints.
- **Accessibility & Theme Toggle:** Dark/Light mode support with fluid transitions, responsive layouts, and print-ready CV/Resume view.

## 🚀 Quick Start

### Prerequisites

- **Node.js** (v18.0.0 or higher recommended)
- **npm** (v9.0.0 or higher)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shubhamh4X/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:3000`.

---

## 📜 Available Scripts

- `npm run dev`: Runs the development server on port 3000 with host binding.
- `npm run build`: Compiles TypeScript and creates an optimized production bundle in `dist/`.
- `npm run preview`: Previews the production build locally.
- `npm run lint`: Performs strict TypeScript validation (`tsc --noEmit`).
- `npm run clean`: Cleans build artifacts (`dist`).
